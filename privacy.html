Privacy Policy

How Pullhub handles local boards, shared boards, Google access, and subscription-related data.

Effective date: June 1, 2026

Pullhub is provided by debutt studio. Contact: support@debutt.studio.

What Pullhub does

Pullhub is a visual reference collection and Google Slides productivity tool. It helps users collect visual references, organize them into local boards, capture screenshots, export backups, share boards when enabled, and push selected images into Google Slides.

Pullhub uses webpage access only when needed to complete an explicit user action, such as Save to Pullhub, Screenshot/Capture, Push to Google Slides, or an export workflow. Pullhub does not continuously monitor webpages, browsing history, visited websites, browser sessions, or background traffic except to the limited extent needed to perform a user-initiated Pullhub action.

Information we process

Pullhub may process image URLs, screenshots or image data selected by the user, page URLs associated with saved references, board names, board notes, Google account email and profile photo after sign-in, Google Slides and Drive identifiers needed to push images, subscription status, and optional shared-board data.

How information is used

Information is used only to provide Pullhub features: saving boards, showing saved references, creating backups, sharing boards, authenticating Google access, pushing images to Google Slides, and managing subscription access.

Where information is stored

Boards are primarily stored locally in the browser using Chrome extension storage. Cloud storage is used only when users intentionally enable sharing or use supported Google integration features. If board sharing is used, shared-board data may be stored in Firebase/Firestore. Images pushed to Google Slides may be uploaded to Google Drive when required so Google Slides can access them.

Google Drive image fallback

Google Slides access is used to insert selected references into the user's presentations. When direct insertion into Google Slides fails because of technical restrictions such as CORS or similar limitations, Pullhub may upload the image to the user's Google Drive folder named "Pullhub Uploads". The uploaded file may be set so anyone with the link can view or read it solely so Google Slides can render and insert the image. This does not grant Pullhub access to the user's entire Google Drive. These files remain in the user's Google Drive and can be managed or deleted by the user.

Google OAuth scopes

The Google presentations scope is used to insert selected images and layouts into Google Slides. The drive.file scope is used only to create and manage Pullhub-created fallback files required for the user's Slides workflow.

Public Share

When Public Share is enabled, Pullhub may store a snapshot representation of the board in Firebase/Firestore. This may include board metadata, layout information, image source URLs, text annotations when applicable, and public share snapshot data. Users can revoke public access by disabling Public Share, deleting the board, or otherwise removing the shared snapshot through normal service operations.

Third-party services

Pullhub uses Google APIs for authentication, Drive, and Slides features; Firebase/Firestore for optional board sharing; and ExtensionPay/Stripe for subscription management.

The Chrome Web Store listing permission description should match the Google Drive image fallback disclosure in this policy.

Google API Limited Use

Pullhub's use and transfer of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Security

Pullhub uses HTTPS for communications where applicable. Google account authorization relies on Google OAuth.

What we do not do

We do not sell user data. We do not use user data for personalized advertising. We do not access browsing activity except as needed for user-facing Pullhub features such as saving the current page URL, capturing selected page content, or detecting Google Slides tabs.

Data deletion

Users may delete boards inside the extension, clear local browser extension data, revoke Google access from their Google Account, or contact support@debutt.studio for help with shared-board or account-related deletion requests.

Changes

We may update this policy as Pullhub changes. Material changes will be reflected on this page.
