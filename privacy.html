Privacy Policy

How Pullhub handles local boards, shared boards, Google access, and subscription-related data.

Effective date: June 20, 2026

Pullhub is provided by debutt studio. Contact: support@debutt.studio.

What Pullhub does

Pullhub is a visual reference collection and Google Slides productivity tool. It helps users collect visual references, organize them into local boards, capture screenshots, export backups, share boards when enabled, and push selected images into Google Slides.

Pullhub only accesses webpage content after explicit user actions such as Save to Pullhub, Screenshot/Capture, Push to Google Slides, or export workflows. Otherwise, Pullhub does not continuously inspect, collect, or analyze webpage content in the background, or monitor browsing history, visited websites, browser sessions, or background traffic, except when necessary for explicit user-initiated Pullhub features.

Data Pullhub may process

Personally identifiable and authentication information. Pullhub may use Google account sign-in status and authentication tokens only to provide Google-connected features requested by the user. These tokens are used to connect to Google Slides and insert references into presentations selected by the user. When necessary, they may also be used to create Google Drive fallback images for that workflow or to authenticate Public Share when the user enables it. Pullhub may also process the Google account email and profile photo returned after sign-in to show account status and support sharing or subscription access.

Website content. Pullhub may access image URLs, page URLs, selected page areas, screenshots, and related page metadata only when the user explicitly saves, captures, or pushes references through Pullhub.

Browser storage. Pullhub stores boards, saved references, notes, settings, and workflow state in browser storage.

Pullhub does not sell user data or use user data for advertising. Pullhub does not transfer user data to third parties except as necessary to provide user-requested functionality, such as Google sign-in, Google Slides insertion, public board sharing, or payment processing.

How information is used

Information is used only to provide Pullhub features: saving boards, showing saved references, creating backups, sharing boards, authenticating Google access, pushing images to Google Slides, and managing subscription access.

Where information is stored

Pullhub follows a local-first storage model. Boards are primarily stored locally in the browser using Chrome extension storage. Cloud storage is used only when users intentionally enable Public Share or use supported Google integration features. If board sharing is used, shared-board data may be stored in Firebase/Firestore. Images pushed to Google Slides may be uploaded to Google Drive when required so Google Slides can access them.

Google Drive image fallback

Google Slides access is used to insert selected references into the user's presentations. When direct insertion into Google Slides fails because of technical restrictions such as CORS or similar limitations, Pullhub may upload the image to the user's Google Drive folder named "Pullhub Uploads". The uploaded file may be set so anyone with the link can view or read it solely so Google Slides can render and insert the image. This link-based permission is for the fallback file used by that workflow. This does not grant Pullhub access to the user's entire Google Drive. The drive.file permission is used only for Pullhub-created fallback files needed for the workflow. These files remain in the user's Google Drive and can be managed or deleted by the user.

Google OAuth scopes

The Google presentations scope is used to insert selected images and layouts into Google Slides. The drive.file scope is used to create and manage Pullhub-created fallback files required for the user's Slides workflow. The drive.metadata scope is used to locate and check metadata for the Pullhub Uploads folder and related Drive files used by the fallback workflow; Pullhub does not read Drive file contents through this scope. The userinfo.email scope is used to show the signed-in Google account, connect account state to Pullhub access, and support Firebase sharing ownership.

Public Share

When Public Share is enabled, Pullhub may store a snapshot representation of the board in Firebase/Firestore. This may include board metadata, layout information, image source URLs, text annotations when applicable, and public share snapshot data. Users can revoke public access by disabling Public Share, deleting the board, or otherwise removing the shared snapshot through normal service operations.

Third-party services

Pullhub uses Google APIs for authentication, Drive, and Slides features; Firebase/Firestore for optional board sharing; and ExtensionPay/Stripe for subscription management.

Google API Limited Use

Pullhub's use and transfer of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Google Slides/presentations permission is used to insert selected references, images, and layouts into Google Slides. Google Drive permissions are used for Pullhub-created fallback image files, related metadata checks, and presentation workflow actions requested by the user. Google account email is used for sign-in state and account-related access.

Security

Pullhub uses HTTPS for communications where applicable. Google account authorization relies on Google OAuth.

What we do not do

We do not sell user data. We do not use user data for personalized advertising. Pullhub does not continuously monitor browsing history, visited websites, browser sessions, or background traffic except when necessary for explicit user-initiated Pullhub features such as saving the current page URL, capturing selected page content, or detecting Google Slides tabs.

Data deletion

Users may delete boards inside the extension, clear local browser extension data, revoke Google access from their Google Account, or contact support@debutt.studio for help with shared-board or account-related deletion requests. Public Share stores a snapshot representation of a board that may include board metadata, layout information, image source URLs, and text annotations when applicable. Disabling Public Share or deleting the board revokes or removes the shared snapshot.

Changes

We may update this policy as Pullhub changes. Material changes will be reflected on this page.
