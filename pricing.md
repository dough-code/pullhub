# Pullhub Pricing

Launch pricing:
- Free: up to 4 boards
- Free: 8 captures to try the full flow
- Free: Push to Google Slides
- Free: ZIP export
- Pro: more room for active projects
- Pro: more export and sharing usage
- Pro: public board sharing links
- Pro: everything in Free
- Pro trial: 14 days
- Pro annual: USD 60/year, equivalent to USD 5/month when billed annually
- Pro monthly: USD 6.99/month

Recommended positioning:
- Free: Try the full Pullhub workflow with a small reference set
- Monthly: Flexible Pro access
- Annual: Best value for active creative work
