Support

When something goes wrong

Use these troubleshooting notes for sign-in, Pro, saving, sharing, Google Slides, and privacy questions.

Quick path

If this is your first time using Pullhub, start with Getting Started. If Pullhub is installed but something is not working, open the matching section below.

Troubleshooting

Account & Login

Use the same Google account

If you use multiple Google accounts, make sure Chrome, Google Slides, and Pullhub are using the same account.

  • Open Pullhub from the Chrome toolbar.
  • Sign out and sign in again if the wrong account appears.
  • Refresh your Google Slides tab after signing in.
Google OAuth

Google says Pullhub has not been verified

This notice can appear while Pullhub is going through Google's app verification review. Only continue if you installed Pullhub from the official Pullhub source.

  • Choose Advanced on the Google notice.
  • Continue to Pullhub if you trust the source you installed.
  • Leave every requested permission checked so Slides detection, image push, and Drive fallback uploads work correctly.

Insufficient authentication scopes

This usually means one or more Google permission boxes were unchecked during sign-in.

  • Sign out of Pullhub.
  • Sign in with Google again.
  • Leave every requested Google permission checked.
  • Refresh your Google Slides tab and try again.
Pullhub Pro

Trial, subscription, and billing

Pullhub Pro includes a 14-day trial. Payments and subscription access are handled through ExtensionPay and Stripe.

  • If Pro does not unlock after payment, reopen Pullhub and wait a moment for license status to refresh.
  • Restart Chrome if Pro still does not appear.
  • Make sure you are using the same email you used for payment.
  • Email support with your payment email and approximate purchase time if access still looks wrong.
Google Slides

Slides is not detected

  • Make sure a Google Slides file is open in Chrome.
  • Confirm Pullhub and Google Slides are using the same Google account.
  • Refresh the Google Slides tab, then open Pullhub again.
  • Sign in again if you skipped any Google permission boxes.

Images are missing or do not push

  • Try pushing fewer images first.
  • If a site blocks an image, Pullhub may save a fallback copy to your Google Drive so Slides can display it.
  • If an image is still missing, capture it with screenshot capture and push again.
Saving & Capture

Save to Pullhub is missing

  • Reload the page after installing or updating Pullhub.
  • The right-click menu usually appears on regular webpage images, not browser pages, Chrome settings, or system pages.
  • Some PDF pages and restricted websites may block extensions.

Capture modes

  • Direct Capture / Alt+Shift+C saves a quick screenshot to the Captures board.
  • Cursor Click-to-Capture lets you click the cursor icon beside a board and capture into that board.
  • Cursor shortcut / Alt+Shift+X starts cursor capture using the last board selected with the cursor icon.

ZIP export is missing images

Some websites block image downloads. Pullhub may export those references as web links in metadata instead of image files. Capture blocked images first when you need the picture file inside the ZIP.

Share Boards

A public link is not updating

Share links are snapshots of a board at the moment you share it. Re-share the board when you want the public version to include new changes.

A shared board says unavailable

  • The board may be private, disabled, deleted, or the link may no longer be valid.
  • If it is your board, turn Public Share back on to create a fresh link.
  • If someone sent you the link, ask the board owner to enable sharing again or send a new link.
Privacy & Data

Where boards are saved

Pullhub boards are primarily saved locally in your browser. Clearing browser data or uninstalling the extension may remove local boards unless you exported a ZIP backup.

Google scopes and Drive fallback

Pullhub uses Google access to detect Slides, insert selected references, and create Pullhub-managed fallback image files when Slides needs a web-accessible image. Pullhub does not use this access to browse your whole Drive.

See the Privacy Policy for the full data and scopes explanation.
